# Wanderlust — Travel & Tourism Experience Platform
**Final Internship Deliverable — CODIORA Web Development Program**

Wanderlust is an intelligent, single-page web platform designed to streamline travel discovery, provide personalized recommendations, offer interactive travel assistance, and manage bookings and itineraries.

## Key Features
* **Interactive Destination Directory:** Filter destinations dynamically by keyword search, travel style (Adventure, Family, Cultural), and budget tier.
* **Smart Recommendation Engine:** A rule-based algorithm that calculates match percentages and generates explanatory reasons based on travel preferences.
* **Interactive Travel Assistant:** Pre-configured FAQ interaction hub delivering immediate travel advice for budget planning, family trips, and trekking packing lists.
* **Services Booking & Community Reviews:** Dynamic user review submission and service booking modal workflows.
* **LocalStorage Trip Planner:** Saves and manages user itineraries persistently within the browser.
* **Dark / Light Theme Switcher:** User-selectable theme persisted across sessions via local storage.
* **Fully Responsive & Accessible:** Crafted with CSS Flexbox/Grid, semantic HTML5, and touch-friendly mobile navigation controls.

## Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Icons & Fonts:** Font Awesome 6, Google Fonts (Poppins)
* **Storage:** Web Storage API (`localStorage`)
